XNU / Núcleo Híbrido de Apple

Tanenbaum y Bos (2015) examinan esta arquitectura de núcleo híbrido que combina componentes del micronúcleo Mach y del sistema operativo FreeBSD para estructurar macOS, iOS, iPadOS y watchOS. Utiliza el módulo Mach para gestionar el aislamiento de hilos de procesamiento, la memoria virtual y la IPC de baja latencia, mientras que la capa FreeBSD aporta las interfaces POSIX y redes. Esta arquitectura híbrida ofrece una elevada estabilidad de kernel unida a compatibilidad estandarizada de software.
