WSL2 / Subsistema de Linux para Windows 2

Silberschatz et al. (2018) describen este subsistema de Microsoft que integra un kernel de Linux real ejecutado sobre una máquina virtual altamente optimizada administrada por Hyper-V en Windows. Proporciona plena compatibilidad con las llamadas al sistema POSIX, permitiendo ejecutar contenedores Docker y herramientas nativas de Linux con acceso directo a archivos. Utiliza un canal de E/S de alta velocidad para sincronizar el sistema de archivos de Linux con el entorno de Windows sin latencias notorias.
