Virtualización / Tecnología de Virtualización

Tanenbaum y Bos (2015) conceptualizan esta tecnología como el medio para abstraer recursos físicos mediante software para ejecutar múltiples instancias independientes de sistemas operativos. Asigna fracciones de procesador, memoria RAM, almacenamiento y conectividad de red de forma aislada a cada máquina virtual. Maximiza el aprovechamiento del hardware de servidores en centros de datos reduciendo costos de energía y espacio. Constituye el pilar fundamental que impulsa la computación en la nube.
