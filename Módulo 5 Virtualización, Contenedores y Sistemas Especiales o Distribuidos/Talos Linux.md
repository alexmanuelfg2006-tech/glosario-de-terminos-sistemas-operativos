Talos Linux / Distribución Inmutable para Kubernetes

Silberschatz et al. (2018) evalúan esta distribución orientada exclusivamente a la ejecución de clústeres de Kubernetes mediante un sistema operativo inmutable administrable por API gRPC. Elimina la consola SSH, los shells interactivos y las herramientas tradicionales de espacio de usuario de Linux, reduciendo a cero la posibilidad de desajustes de configuración manuales. El sistema se actualiza de forma atómica y completa desde imágenes consolidadas en red. Ofrece un entorno altamente seguro, automatizado y auditable.
