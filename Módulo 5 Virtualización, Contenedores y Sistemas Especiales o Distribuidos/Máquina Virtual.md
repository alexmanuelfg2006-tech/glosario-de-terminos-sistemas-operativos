Máquina Virtual / Entorno de Computación Emulado

Tanenbaum y Bos (2015) definen este entorno como una instancia informática virtualizada que ejecuta un sistema operativo completo aislado sobre recursos de hardware emulados o pasados por hardware. Operando bajo el control de un hipervisor, cada máquina virtual posee sus propios controladores, núcleo, tablas de páginas y espacio de usuario independientes. Permite consolidar múltiples servidores físicos heterogéneos en una sola máquina anfitriona reduciendo costos de infraestructura. Mantiene un nivel de aislamiento muy elevado frente a fallos y amenazas.
