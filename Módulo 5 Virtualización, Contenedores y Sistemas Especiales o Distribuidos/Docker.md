Docker / Docker

Silberschatz et al. (2018) analizan esta plataforma de software orientada a automatizar la creación, distribución y ejecución de contenedores livianos independientes del entorno. Utiliza los recursos de aislamiento nativos del kernel Linux, como cgroups, namespaces y sistemas de archivos superpuestos OverlayFS. Permite empaquetar aplicaciones junto a sus bibliotecas exactas en imágenes OCI portables de rápida instanciación. Al compartir el kernel del host sin requerir hipervisores pesados, optimiza drásticamente la densidad de despliegue en servidores.
