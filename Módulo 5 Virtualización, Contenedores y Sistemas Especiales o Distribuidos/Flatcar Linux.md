Flatcar Linux / SO Inmutable para Contenedores

Silberschatz et al. (2018) presentan esta distribución de Linux mínima diseñada con un sistema de archivos de solo lectura para ejecutar cargas de trabajo en contenedores de manera segura. Elimina gestores de paquetes tradicionales y herramientas en espacio de usuario no esenciales, reduciendo la superficie de ataque del entorno. Las actualizaciones del sistema operativo se aplican de forma atómica mediante un esquema de doble partición raíz A/B con reversión automática ante fallos. Se administra de forma declarativa y se utiliza para clústeres nativos de nube.
