ApacheBench (ab) / Medidor de Carga HTTP

Tanenbaum y Bos (2015) revisan el uso de esta utilidad de línea de comandos diseñada por la Apache Software Foundation para evaluar la velocidad y capacidad de respuesta de servidores web bajo estrés. Funciona simulando múltiples peticiones simultáneas sobre un puerto HTTP o HTTPS específico para medir variables de concurrencia y latencia. Permite a los administradores identificar cuellos de botella en la asignación de sockets del sistema operativo y cuotas de procesador. Los resultados detallan métricas de peticiones por segundo, tiempo medio de procesamiento y distribución porcentual de respuestas.
