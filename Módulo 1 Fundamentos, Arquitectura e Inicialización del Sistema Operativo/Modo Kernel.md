Modo kernel / Kernel Mode

Según Silberschatz et al. (2018), el modo kernel (también conocido como modo supervisor o privilegiado) es un estado de ejecución del procesador en el que el código que se está ejecutando posee acceso ilimitado a toda la memoria y a todas las instrucciones de máquina, estando reservado exclusivamente para las funciones internas del núcleo. El modo kernel es el que tiene mayor privilegio en el sistema y tiene control del hardware y la memoria 
### Cita
Silberschatz, A., Galvin, P. B., & Gagne, G. (2018). _Operating System Concepts_ (10.ª ed.). Wiley. Capítulo 1
