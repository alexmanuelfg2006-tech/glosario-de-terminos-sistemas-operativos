# Sistema Operativo

### Término técnico 
Sistema Operativo (SO) / _Operating System (OS)_.

### Definición formal
Un sistema operativo es un programa que actúa como intermediario entre el usuario y el hardware de la computadora. El propósito de un sistema operativo es proporcionar un entorno en el cual el usuario pueda ejecutar programas de manera conveniente y eficiente

### Rol operativo / utilidad 
Asigna recursos de forma controlada (planificación de CPU, memoria virtual, sistemas de archivos), aísla procesos entre sí y hace que el hardware sea cómodo de usar.
