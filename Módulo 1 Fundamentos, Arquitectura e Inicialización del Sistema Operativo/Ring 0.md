Anillo 0 / Ring 0 

Según Tanenbaum y Bos (2015), el Ring 0 es el nivel de protección más interno y privilegiado en arquitecturas x86, diseñado para ser utilizado de manera exclusiva por el núcleo del sistema operativo y los controladores críticos para ejecutar instrucciones de máquina de bajo nivel. Es el nivel mas alto de privilegio donde se ejecuta el kernel

### Referencia
Tanenbaum, A. S., & Bos, H. (2015). _Modern Operating Systems_ (4.ª ed.). Pearson. Capítulo 2
