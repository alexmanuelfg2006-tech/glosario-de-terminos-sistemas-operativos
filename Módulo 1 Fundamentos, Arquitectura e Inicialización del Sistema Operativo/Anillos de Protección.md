***Anillos de protección  / Protection Rings

**Jerome H. Saltzer** y **Michael D. Schroeder**(1975) Describieron una estructura de **círculos concéntricos** numerados del 0 al 7, donde el nivel de privilegio es inversamente proporcional al número del anillo donde el Anillo 0 tiene máximo privilegio y el Anillo 7 tiene el mínimo. Los anillos son lo que define el privilegio que se tiene sobre el sistema operativo, estos se simplificaron a 4 anillos , 0 para el modo kernel y 3 para el modo usuario 1 y 2 para controladores o servicios del sistema.
