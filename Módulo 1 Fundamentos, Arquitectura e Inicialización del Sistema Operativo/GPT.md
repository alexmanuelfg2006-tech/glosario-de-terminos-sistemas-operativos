Transformador Generativo Preentrenado / Generative Pre-trained Transformer

Alec Radford, Karthik Narasimhan, Tim Salimans ,Ilya Sutskever (2018)  Definen a GPT como un sistema de aprendizaje profundo semi-supervisado que se divide estrictamente en dos etapas: **Preentrenamiento generativo no supervisado**: El modelo lee cantidades masivas de texto y aprende a predecir cuál es la siguiente palabra en una secuencia. **Ajuste fino supervisado**: El modelo entrenado se adapta a una tarea específica utilizando un conjunto de datos mucho más pequeño. GPT el es sistema de aprendizaje con el que se entrenan a las inteligencias artificiales 

### Referencia
Radford, A., Narasimhan, K., Salimans, T., y Sutskever, I. (2018). _Improving language understanding by generative pre-training_. OpenAI. openai.com
