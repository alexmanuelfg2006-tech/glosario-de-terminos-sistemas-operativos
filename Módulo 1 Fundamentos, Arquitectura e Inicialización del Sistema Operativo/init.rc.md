Script de configuración del inicio (init.rc) / init.rc configuration script

Según Yaghmour (2013), init.rc es el archivo de configuración estructurado en un lenguaje de scripts propio del entorno Android que el demonio init interpreta durante el arranque para montar sistemas de archivos, configurar propiedades del sistema y lanzar los servicios nativos básicos de la plataforma. Es el primer programa que se inicia al enceder un dispositivo android

