Modo usuario / User Mode

Según Silberschatz et al. (2018), el modo usuario es un estado de ejecución restringido del procesador asignado a las aplicaciones del usuario, en el cual este carece de acceso directo al hardware o a las instrucciones privilegiadas del sistema para prevenir daños o interferencias entre procesos. El modo usuario es el que se utiliza para ejecutar aplicaciones sin poner en riesgo la seguridad del sistema

### Referencia
Silberschatz, A., Galvin, P. B., & Gagne, G. (2018). _Operating system concepts_ (10.ª ed.). Wiley. Cap. 1
